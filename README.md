## About

I like taking a product from the very first schema to what actually runs in production, as one connected system rather than a pile of disconnected parts.

A lot of my work sits at the point where messy real-world operations meet clean, reliable software: real-time event-driven systems, retrieval and agent orchestration, and the evaluation and guardrails that make an LLM workflow safe enough to be trusted with real operations. I design for GDPR compliance and EU data residency across both commercial cloud APIs and self-hosted local models.

I question what "real-world" actually means, and then I build for it.

**Currently:** AI Engineer @ KIWI Vapor · Full Stack Developer & AI Systems Architect @ PappaChat · Full Stack Developer & LLMOps @ CrowdM

**Learning by building:** moving a container-first service onto Azure — Container Apps, Key Vault with managed identity, Bicep, GitHub Actions with OIDC.

## What I Do

- **Ship full products end to end.** Schema design, APIs, frontend, authentication, billing and AI features, built as a single coherent system.
- **Architect AI-native systems.** Hybrid LLM pipelines, RAG with hybrid search and reranking, structured extraction, MCP servers, tool calling and agent orchestration in real production settings.
- **Build the harness, not just the agent.** Tool registry, schema validation, allow-lists, step and cost caps, and human approval before anything irreversible.
- **Own reliability and cost.** Evaluation sets before rollout, output validation, deterministic fallbacks, model routing, semantic and prompt caching, tracing and latency budgets.
- **Own the whole delivery pipeline.** From local development to production: Git workflows, infrastructure setup, automated deployments and day-to-day production operations.
- **Turn product into systems.** I translate business requirements into scalable, maintainable software, connecting product thinking with engineering execution.
- **Design for scale.** Container-first and provider-portable architecture that stays healthy as usage grows.
